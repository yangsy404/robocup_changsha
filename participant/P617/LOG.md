## 2026-10-02

- 鲁棒性抽查：把公开套件 `scenario_seed` 换成 5 组新种子重跑，分数 0～250 剧烈波动
  （orig 225 / v1 208 / v2 133 / v3 192 / v4 250 / v5 0）。
- 定位原因：分数由「开局机器人-目标最近距离」决定，而非策略缺陷。物理上限——10 步机器人
  最多移动约 0.29、覆盖判定半径 0.15，开局距离 > 0.44 的目标基本够不着；v5 四个场景的
  最近距离都在 0.55 以上，0 分是几何上限，不是 bug。
- 尝试「无目标搜索回退」（不可见时朝按编号分散的锚点移动），重跑 6 组种子分数完全不变，
  证明该路径无用（目标太远，搜索移动的 0.29 也不够），已 `git checkout` 回退，
  entry.py 恢复为已验证的 225 版本（提交 6c7cbcf）。
- 结论：225 已接近物理天花板，分数方差是 benchmark 初始布局的固有属性，规则策略无法消除。

## 2026-10-02（最终低风险 ablation）

对两份外部建议（全局分配、PD+前馈）做最后一次可逆 ablation，门槛：**orig 不降 且 均值稳定提升才合并**。

- 全局最小代价分配（替换贪心，`_global_assignment`，枚举排列求二分匹配）：6 组种子 Pareto 改进——
  orig 225 不变、v1 208.33→216.67、v3 191.67→200.00、其余不变，均值 168.06→170.83，
  0 碰撞、无任何种子回退 → **合并**。
- PD 相对速度阻尼（`KV=1.0`，期望速度加 `KV*(目标速度-自身速度)`）：orig 225→208.33、
  v4 250→208.33，均值 168.06→152.78，全场景变差 → **放弃**。
  原因：10 步内机器人须全速够目标，阻尼在接近时减速反而错过覆盖，物理上限下 bang-bang 最优。
- 未做：编队/覆盖几何（与「每个目标最多记 1 台机器人」的二分匹配评分冲突，是负优化）、
  领域随机化/在线辨识/分层 RL（真机方向，本赛动力学为冻结参数，2 天截止内无意义）。
- 第二轮定向扫描（进程内 monkeypatch 类属性，脚本 outputs/P617/sweep.py）：
  - LEAD_STEPS 2.0/2.5/3.0/3.5/4.0：2.5 为 Pareto 最优点（v1 216.67→225，其余不变，
    均值 170.83→172.22，0 回退）；3.5 无变化，2.0 与 4.0 有回退 → 采纳 2.5。
  - KV 目标速度前馈 0.1~0.4：与基线逐字节一致，零效果（3 步 lead 隐含 9× 前馈已吃满、被
    V_MAX 封顶）→ 回退 KV 项，不留死代码。
  - AVOID_GAIN=0 消融：出现碰撞（max 0.10）、3 个种子回退（均值 170.83→166.94）→
    证明避撞在挡真实碰撞，保留 0.6。
- 最终提交 = 225 orig 版本 + 全局最小代价分配 + LEAD_STEPS=2.5（6 种子均值 172.22，无回退）。
